# About the dataset

This project does not download data from Kaggle. Instead, `src/generate_data.py` generates a synthetic
mobile money transaction dataset, following the well-established PaySim column schema (Lopez-Rojas et
al.; also used in Lokanan, 2023, *Applied AI Letters*) so results stay comparable to the literature this
paper cites. Fraud cases are injected to match typologies documented specifically in the Nigerian and
African fintech literature, rather than generic card-fraud patterns.

Running the script produces:

- `data/paysim_synthetic.csv`
- `data/paysim_synthetic.json`

Neither file is committed to git (see `.gitignore`) — they're regenerated by running the script, so the
generation code is the real artifact, not the raw data itself.

**NB:** this is a synthetic dataset generated to model documented fraud typologies from the literature,
not real transaction data. That is a legitimate and common approach — several of the cited papers note
that real fintech transaction data is confidential and not publicly available.
